# SnapBack Roadmap

Future improvements and feature ideas.

## Completed

- [x] CLI tool with subcommands (install/status/on/off/uninstall)
- [x] One-liner installation (`curl | bash`)
- [x] Update command (`snapback update`)
- [x] Non-interactive install (`snapback install -y`)

## Planned

### High Priority
- Safari browser support (different AppleScript syntax)

### Medium Priority
- Debug/verbose mode for troubleshooting
- Pause other media apps (VLC, Spotify, Apple Music)

### Nice to Have
- macOS menubar app with on/off toggle
- macOS Focus modes integration

### Future
- Windows/Linux support
